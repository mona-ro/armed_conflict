# Armed Conflict Analysis

This repository contains the Quarto in-class assignment for CHL5233H Statistical Programming and Computation.

## Contents

* `data/raw/` — Raw country and regional data files
* `reports/` — Quarto analysis and rendered PDF report

## Analysis

The analysis examines the distribution of countries across regions and sub-regions using R, including summary tables and a bar chart created with `ggplot2`.
